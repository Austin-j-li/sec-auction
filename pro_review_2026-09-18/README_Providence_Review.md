# Providence review package

Start with `Providence_Four_Run_Comparative_Assessment.md`.
The overall artifact ranking is Astra > Fable > DeepSeek > Muse, with a close first/second comparison.

For a new extraction, attach:
1. your existing `SEC_Merger_Auction_Extraction_Instruction.md`;
2. `SEC_Readable_Excel_Output_Instruction.md` (controls conflicting output requirements);
3. the complete new filing.

Open `Providence_Worcester_Review_Demonstration.xlsx` to inspect the five-sheet review design.
It is an independently adjudicated demonstration, not a fifth benchmark run or a human-approved dataset.
Read the seven Review decisions and the separate AI change log. Human corrections are blank.

`Future_Lower_Cost_Extraction_Development.md` is a separate exploratory discussion.
It does not recommend switching to a cheaper extractor now.

`Providence_Audit_Manifest.json` records original hashes and the limited mechanical checks.
The optional `Providence_Demo_Snapshot.json` contains the demonstration records and source texts;
it is a machine-readable companion, not a replacement for ordinary workbook review.

All four submitted workbooks were left unchanged. They are not copied into this download package.
The original filing is included so its filename-based references remain available.
