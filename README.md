# SEC deal-ledger project

This repository turns the “Background of the Merger” in a supplied SEC filing into a four-sheet Excel deal ledger for takeover-auction research. The working extraction instruction is [v1.13.2](SEC_Deal_Ledger_Extraction_Instruction.md) and is frozen. An agent performing a deal extraction must follow [AGENTS.md](AGENTS.md): use only that instruction and the assigned filing in `raw_filing/`; development and review documents are outside the extraction input.

For current pipeline and review status, start with the [development handoff](_dev/HANDOFF.md). The [cockpit guide](_dev/cockpit/README.md) explains review and editing, while [research questions](_dev/RESEARCH_QUESTIONS.md) distinguishes resolved decisions, pending deal choices and provisional conventions. The [Datalink](_dev/reviews/2026-09-21-datalink-pilot/README.md) and [Mac-Gray](_dev/reviews/2026-09-21-mac-gray-pilot/README.md) packet entry points map older reports to the current extraction. The [chronology](_dev/CHRONOLOGY.md) indexes historical instruction and review evidence; the [documentation audit](_dev/maintenance/2026-09-22-doc-refresh/README.md) records the current navigation refresh and protected-file checks.

The current extractions in `extraction/` are not automatically human-adjudicated or research-ready. Checker results are mechanical. The handoff states the review boundary for each deal.
