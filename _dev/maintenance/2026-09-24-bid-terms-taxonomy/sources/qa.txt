P3: M&A Bidding Extraction Pipeline

P4: Q1 — Same output across runs

P5: Step 2. Does LLM always produce the exact same output or is there variation across runs? I think this is answered in Determinism and reproducibility.

P6: Austin — 2 Aug 2026

P7: No. The LLM does not produce exactly the same output on every run. The extraction request sets no temperature, and the providers use models that can vary their answers. A new run may therefore change the wording, the quote selected, or the number of claims. The comparison program in pipeline/stability.py measures this variation across saved runs. The current release report, quality_reports/stability/target-release-proof.json, classifies the reference set as STABLE_FOR_REFERENCE_REVIEW. That classification allows the content to vary but does not allow the required output structure to change. After extraction, the remaining steps are fixed computer instructions. If we create the CSV again from unchanged snapshots, the resulting file is identical word for word.

P8: Austin — 7 Aug 2026

P9: The same accepted records reproduce the same ledger. A fresh language-model reading can differ in wording or in which facts it selects, so this delivery rests on the preserved reviewed records and their filing quotations rather than on a new reading.

P10: Q2 — Paragraphs split across pages

P11: Step 2. Does LLM understand page numbers which can “break” the paragraph? What if, e.g., a part of info about a bid is on page 35 and a part – on page 36, and it is the same paragraph in the background? Would LLM recognize this as a single paragraph and glue together ‘claim’ information?

P12: Austin — 2 Aug 2026

P13: The model receives paragraphs one page at a time, so one evidence quote cannot cross a page boundary. If it tries to join text from two page units into one quote, the computer rejects the quote and instructs the model to provide a separate evidence reference for each unit. A single claim can still cite several pieces of evidence. Each piece must quote its own page exactly. That is how the system captures a fact that continues onto another page. In the CSV, the pages and quotes are separated by vertical bars. One Providence & Worcester bid row, for example, has evidence_page 36 | 36 | 37. The system does not combine the page fragments into a new paragraph that was not present in the filing.
